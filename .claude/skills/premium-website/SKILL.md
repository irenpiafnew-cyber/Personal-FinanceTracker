# Преміальний сайт за 5 кроків

## 1. Бриф (питай максимум 2 питання, решту — припусти)
- Про що сайт і для кого?
- Настрій у 3 словах (напр. «тихий, дорогий, сміливий»).

## 2. Концепція (покажи до коду, коротко)
| Параметр | Рішення |
|---|---|
| Палітра | фон / текст / акцент (HEX) |
| Шрифти | заголовки + текст (Google Fonts) |
| Секції | Hero → Про → Переваги/Роботи → Відгук → CTA → Футер |
| Вау-момент | один: split-text reveal, горизонтальний скрол, магнітна кнопка, 3D-об'єкт |

## 3. Код
- Файл: `projects/sites/<slug>/index.html`.
- Каркас: `templates/starter.html` з цієї папки — скопіюй і наповнюй.
- Кольори тільки через CSS-змінні; темна тема через `prefers-color-scheme`.
- Анімації: GSAP + ScrollTrigger з CDN, плавний скрол — Lenis.
- Обгорни анімації в перевірку `prefers-reduced-motion`.

## 4. Чекліст якості
- [ ] 375px: нічого не вилазить, кнопки ≥ 44px
- [ ] Заголовок через `clamp()`
- [ ] Реальні тексти, без lorem ipsum
- [ ] `<title>`, meta description, og:image
- [ ] Зображення з `loading="lazy"` і `alt`

## 5. Навчальний блок
Наприкінці: «Що тут варто запам'ятати» — 2–3 прийоми з цього сайту + 2 варіанти, що покращити далі.
