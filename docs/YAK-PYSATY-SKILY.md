# Як писати скіли для Claude Code — шпаргалка

## Що таке скіл
**Скіл = рецепт.** Папка з файлом `SKILL.md`, де описано, як робити певну задачу завжди однаково добре. Claude сам підтягує скіл, коли твоє прохання збігається з його описом, або ти викликаєш його явно: `/назва-скіла`.

| | Скіл | Агент | CLAUDE.md |
|---|---|---|---|
| Що це | Рецепт задачі | Окремий «співробітник» зі своєю роллю | Загальні правила проєкту |
| Де лежить | `.claude/skills/<name>/SKILL.md` | `.claude/agents/<name>.md` | корінь проєкту |
| Коли діє | Коли задача підходить | Коли Claude делегує йому | Завжди |
| Приклад | «Сценарій шортсу» | «Відеопродюсер» | «Відповідай українською» |

## Анатомія SKILL.md
```markdown
---
name: short-video            ← лише малі латинські літери й дефіси
description: Пише сценарій … Використовуй, коли просять «сценарій», «тікток».
---
# Тіло: інструкції, кроки, шаблони
```

### Найважливіше — `description`
Claude бачить спочатку **тільки його**, і за ним вирішує, чи брати скіл. Формула:
> **[Що робить] + [результат] + «Використовуй, коли …» + [слова, якими ти просиш]**

❌ `description: Скіл для відео`
✅ `description: Пише сценарій 30-секундного ролика для TikTok/Shorts з хуками й розкадровкою. Використовуй, коли просять «сценарій», «ідею для тіктоку», «рілс».`

## 7 правил хорошого скіла
1. **Одна задача — один скіл.** «Все про відео» — погано; «сценарій шортсу» — добре.
2. **Кроки нумеровані й перевірювані.** Не «зроби гарно», а «заголовок ≤ 60 символів».
3. **Дефолти замість питань.** «Якщо не сказано — 30 секунд».
4. **Покажи формат виходу** — таблицю чи шаблон.
5. **Чекліст наприкінці** — Claude сам себе перевірить.
6. **Важкий вміст — в окремі файли** (`templates/`, `examples/`), SKILL.md хай буде коротким.
7. **Тестуй і покращуй.** Помітила помилку — допиши правило в скіл.

## Твоя практика (по зростанню складності)
1. Відкрий `.claude/skills/short-video/SKILL.md` і зміни дефолтну довжину на 45 с.
2. Скажи: «/skill-writer — хочу скіл для каруселі в Instagram».
3. Напиши сама скіл `thumbnail-idea` (ідеї обкладинок для YouTube) і попроси мене зробити рев'ю.
4. Додай до скіла папку `examples/` з 2 вдалими прикладами — побачиш, як зросте якість.
